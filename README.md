# vite-electron-template

vite-electron-template

## Framework packages

Vite + Vue + Electron + Pinia + Vue Router + TypeScript + TDesign Vue + Unocss

## Package Manager

pnpm

## Quick start

```
git clone https://github.com/xinlei3166/vite-electron-template
```

## Project setup

```
pnpm install
```

## dev

```
pnpm dev
pnpm dev:electron
```

## build

```
pnpm build
pnpm build:win
pnpm build:mac
```
